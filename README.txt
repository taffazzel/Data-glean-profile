DATA GLEAN WEBSITE

Run locally on macOS:
1. Open Terminal.
2. cd to this folder, for example:
   cd ~/Downloads/data-glean-premium
3. Run:
   python3 -m http.server 5001
4. Open:
   http://localhost:5001

Stop the server with Control + C.

Main files:
- index.html: content and links
- styles.css: layout and visual design
- script.js: animated data wave, menu and scroll effects
- assets/: founder photo and downloadable CV
